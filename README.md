Squidweird
Version: 1.0
Size (Zipped): 42 MB

A 2D Unity platformer prototype where the player uses multiple “tentacles” as a physics-based grappling and swinging system. The project focuses on grappling mechanics, platforming, and experimental interactions (e.g., temporary platforms between two anchors).

Features

Multiple tentacles with spring physics, target tracking, and break logic under high force.
Grappling to anchor points with dynamic strand length.
2D platforming with jump/run, respawn system, and level progression.
UI menu and audio/SFX management.
Controls (Default)

A/D: Move
Space: Jump
Left Mouse: Attach active tentacle
Right Mouse: Detach active tentacle
Mouse Wheel or 1-5 : Switch active tentacle
W/S: Extend/shorten tentacle
E: Detach all tentacles
F: Grow new segemnts starting from the anchor you are attached to
C: Cut active tentacle
Q: Auto attach to a neare anchorpoint (available if anchor pulsates)
O,P: zoom-in and out
Esc: In-game menu

Playing the Game:
Clone Repo and start the game by running BeardClimbing.exe
Or
Download Squidweird_exe.zip and start the game by running BeardClimbing.exe in the folder.

Known Issues

You may encounter invisible walls; you can overcome them by jumping or briefly moving in the opposite direction.
If you run into issues with your tentacles, press K to reload the tentacles.
The Tentacle control is currently device(FPS) dependent. This may alter game-experience as the control was finetuned to unity.
We are working on a fix for this problem.


Please let us know if you find any bugs or issues.
