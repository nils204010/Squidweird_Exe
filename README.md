# Squidweird
2D Plattformer Game about a Squid trying to reach the water. 
Version: 1.0
Size (Zipped): 42 MB

Playing the Game:
Clone Repo and start the game by running BeardClimbing.exe

Or

Download Squidweird_exe.zip and start the game by running BeardClimbing.exe in the folder.

Please let us know if you find any bugs or issues.

Known issues/Bugs:

1: The Tentacle control is currently device(FPS) dependent. This may alter game-experience as the control was finetuned to unity.
We are working on a fix for this problem.

2: Sometimes the player experience a sudden stop when walking within the level (as there would be an invisible wall). When moving back and forth again its gone.
We are working on a fix for this problem.
